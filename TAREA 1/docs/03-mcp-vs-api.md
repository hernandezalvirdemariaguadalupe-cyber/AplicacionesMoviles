# 3. MCP frente a una API (punto obligatorio)

> Estado: pendiente

- [ ] Qué es una API: contrato entre programas, decisión de qué/cuándo llamar escrita de antemano en el código.
- [ ] Qué es MCP: protocolo abierto basado en JSON-RPC 2.0; el servidor publica un catálogo de herramientas (nombre, descripción, esquema de parámetros); el modelo descubre el catálogo en tiempo de ejecución y decide qué invocar.
- [ ] Tabla comparativa (mínimo): quién decide qué se invoca, cómo se descubren las capacidades, acoplamiento cliente-servicio, formato de mensajes, autenticación y consentimiento, reutilización entre aplicaciones.
- [ ] Aclarar explícitamente: MCP NO sustituye a las APIs; casi siempre envuelve una API o recurso existente.
